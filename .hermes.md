# BoardGame Vault — Project Rules (Hermes)

Repo: `/home/ubuntu/projects/Boardgame-Collection`
App gốc export từ Google AI Studio Build mode (React 19 + Vite 8 + TS + Tailwind 4).

## Bắt buộc đọc trước khi làm
Đọc `HANDOFF.md` ở root repo — nó chứa trạng thái hiện tại, lỗi đang mở và các quyết định đã chốt.

## Cài đặt & chạy

```bash
npm install --legacy-peer-deps   # BẮT BUỘC --legacy-peer-deps
npm run dev                      # vite --port=3000 --host=0.0.0.0
npm run build                    # vite build
npx tsc --noEmit                 # typecheck, phải sạch 0 lỗi
```

`--legacy-peer-deps` là bắt buộc: AI Studio pin `esbuild ^0.25.0` trong devDependencies
nhưng Vite 8 yêu cầu peer `esbuild ^0.27.0 || ^0.28.0`. Cài bằng `npm install` thường sẽ fail ERESOLVE.
Repo có `bun.lock` nhưng máy này không có bun — dùng npm.

## Quy ước làm việc với user

- User là Nguyễn Quốc Huy, giao tiếp tiếng Việt, không phải dev chuyên. Giải thích ngắn, dùng từ dễ hiểu.
- Sau MỖI thay đổi code: chạy `npx tsc --noEmit` + `npm run build`, rồi chụp màn hình gửi user.
  Chụp bằng headless Chromium của playwright:
  ```bash
  /home/ubuntu/.cache/ms-playwright/chromium-1234/chrome-linux/chrome \
    --headless=new --disable-gpu --no-sandbox --hide-scrollbars \
    --window-size=1440,1000 --screenshot=/tmp/shot.png --virtual-time-budget=6000 \
    http://127.0.0.1:3000/
  ```
  Rồi gửi `MEDIA:/tmp/shot.png`.
- Công cụ `browser_exec` BỊ CHẶN với `127.0.0.1` (private address). Muốn ĐO layout (không chỉ nhìn ảnh)
  thì dùng script CDP: `/home/ubuntu/.hermes/scripts/cdp_probe.py`
  ```bash
  python3 ~/.hermes/scripts/cdp_probe.py 'http://127.0.0.1:3000/' 'return JSON.stringify({...});' \
    --width 1440 --height 1000 --wait 4 [--click "<JS click>"] [--shot /tmp/x.png]
  ```
  Nó tự bật Chromium headless ở debug port 9334, chạy JS đo đạc, chụp ảnh, rồi tắt.
  Dùng để verify: `document.documentElement.scrollWidth` vs `innerWidth` (tràn ngang),
  `scrollWidth > clientWidth` (text bị cắt "..."), `getBoundingClientRect()` (kích thước/thẳng hàng).
- Port 3000 KHÔNG mở ra internet (firewall chặn), user không tự mở link được. Muốn user xem thì gửi ảnh chụp.
- Không sửa code song song trong AI Studio — Hermes là nhà chính, tránh conflict khi sync 2 chiều.
- Dev server chạy nền bằng `terminal(background=true)`, không dùng nohup/disown (Hermes chặn).

## Kiến trúc

Frontend-only SPA, không có backend thật (thư mục `express`/`server.js` chỉ là script `clean`, không dùng).
State lưu localStorage; đăng nhập qua Firebase; dữ liệu game sync từ Google Sheet công khai.

**App KHÔNG gọi Gemini API** — không có import `@google/genai` nào trong `src/`.
`GEMINI_API_KEY` trong `.env.example` là boilerplate của AI Studio, không cần cho app chạy.
